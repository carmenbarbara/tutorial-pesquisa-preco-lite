# Tutorial Pesquisa de Preços Lite

Este repositório contém a documentação e o manual de utilização do sistema **Pesquisa de Preços Lite**, desenvolvido em MkDocs com o tema Read the Docs.

## Estrutura do Repositório

- `.readthedocs.yaml`: Configuração para build no Read the Docs.
- `mkdocs.yml`: Arquivo principal de configuração do MkDocs.
- `docs/`: Pasta contendo o código-fonte da documentação em Markdown, CSS, JS e imagens.
  - `docs/Imagens/`: Pasta para o armazenamento de prints e imagens do sistema.
  - `docs/css/`: Estilos customizados (`extra.css`).
  - `docs/js/`: Scripts JavaScript (`custom.js` e `font-size.js`).
